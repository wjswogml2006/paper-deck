# Paper Deck — 문헌 관리 대시보드

논문/문헌을 정리·분석하기 위한 단일 HTML 파일 기반 대시보드입니다.
별도 서버나 빌드 과정 없이 `index.html`을 브라우저로 열기만 하면 바로 사용할 수 있습니다.

## 특징
- 논문별 요약(TL;DR), 연구질문, 방법론, 결과, 한계점, 후속 액션 등을 구조화된 카드로 관리
- 태그/주제/방법론/중요도/인용상태 기준으로 검색 및 필터링
- Chart.js, D3.js를 이용한 통계·관계 시각화
- 데이터는 `index.html` 내부의 `papers` 배열(JS 객체)에 저장됨 (별도 DB 없음)

## 사용 방법
1. `index.html`을 로컬에 다운로드
2. 브라우저(Chrome, Edge 등)에서 더블클릭하거나 `open index.html`로 실행
3. 논문 데이터를 추가/수정하려면 `index.html` 안의 `let papers = [...]` 배열을 직접 편집

> `papers` 배열의 각 항목 스키마는 `index.html` 상단 `DATA MODEL` 주석에 정의되어 있습니다.
> 추후 BibTeX → JSON 변환 스크립트를 만든다면, 이 스키마 그대로 출력하면 바로 로드할 수 있습니다.

## 데이터 편집 시 주의
- 현재 포함된 5개 논문 항목은 **예시(샘플) 데이터**입니다. 실제 문헌 정보로 교체해서 사용하세요.
- 개인 연구 노트/미공개 자료가 포함될 수 있으므로, 공개 저장소로 만들 경우 민감한 내용이 없는지 확인하세요.

## 배포 (선택)
정적 파일이므로 GitHub Pages로 바로 배포할 수 있습니다.
1. 저장소 Settings → Pages
2. Source를 `main` 브랜치 / `root`로 설정
3. 저장 후 `https://<username>.github.io/<repo>/` 에서 접속 가능
